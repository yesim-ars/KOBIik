Ekranlar arasındaki akış

Aday tarafında:
İlan listesi → İlan detayları → Giriş/kayıt → Özgeçmiş seçimi → Başvuru gönderme → Başvurularım

İşveren tarafında:
Giriş → Ana panel → İlan seçimi → Başvurular / Aday havuzu → Aday detayları → Karar destek sonucu → Değerlendirme durumu

Dışarıdan aday ekleme akışı ise şöyle olacak:
Aday havuzu → Aday ekle → Bilgileri ve özgeçmişi kaydet → İlanla ilişkilendir → Değerlendirmeyi başlat


Aday henüz bir ilana bağlanmamışsa genel aday havuzunda bulunabilir; ancak eşleştirme için bir pozisyon seçilmesi gerekir.
